# 写真とリンク情報

## 操作

「追加」ではタイトル、URLの順に入力します。URLを貼ると、タイトルと写真を取得します。手入力済みのタイトルは上書きしません。取得結果は編集でき、写真だけ外すこともできます。写真のない項目も保存できます。

やりたいことの詳細でも写真を追加できます。「思い出に残す」で実行済みにしても、写真と表示形式は維持されます。日付は編集画面で変更できます。「写真を追加」では複数選択でき、写真を押すと全体を表示します。左右ボタン・矢印キーで切り替え、Escapeキーで閉じます。「やりたいことに戻す」でも写真は保持されます。

ホームには、このブラウザで使ったグループが最大12件並びます。履歴から外してもグループ本体は削除されません。共有URLと表示名は端末のローカルストレージに保存します。

## 保存方式

- グループと項目は引き続きDynamoDBに保存します。既存項目は新しいフィールドがなくても「やりたいこと」として表示します。
- 項目に`coverImageUrl`、`status`（`wish` / `memory`）、`completedAt`（日付）、`photos`を追加します。
- 写真の実体は静的サイト用とは別の非公開S3バケットに保存します。写真の参照には有効期間1時間の署名付きURLを使い、署名付きURL自体はDBに保存しません。
- グループの認可後、有効期間5分・サイズ上限付きの署名付きPOSTを発行します。アップロード先は一時領域です。
- 確定APIで形式とサイズを検査し、検証したバイト列を別のランダムキーへ保存してからDBへ関連付けます。一時キーの再アップロードで確定済み写真を変更できません。
- 同時編集では更新日時を条件に書き込み、競合時は409を返します。失敗した確定写真は片付けます。未確定アップロードはS3ライフサイクルで1日後から削除対象になります。
- 写真バケットはスタック削除時も保持します。既存DynamoDBテーブルは従来の削除設定のままです。スタック削除時は写真への参照情報も失われるため、データを保持する運用ではテーブルの保持設定も合わせて変更してください。

## 制限

- 1つの項目に50枚まで。JPEG・PNG・WebP、保存時1枚8MBまで。
- ブラウザで長辺2400px以内のJPEGへ変換し、位置情報などのEXIFを引き継ぎません。変換前は30MBまで。HEICはブラウザが読み込める場合に対応し、非対応時は別形式の選択を案内します。
- 共有URLを知る人は写真も閲覧・追加・削除できます。メンバー別の権限はありません。
- リンク先のOGP / Twitterカード / titleを使います。ログイン必須・JavaScriptによる描画・取得拒否などのページでは自動取得できません。
- URL取得では公開HTTP(S)アドレスだけを許可し、DNS解決結果を検査したIPへ接続します。リダイレクト先も検査し、8秒・HTML 1MB・リダイレクト3回に制限します。
- リンク先画像は外部URLを直接表示します。配信元での変更や削除が反映されます。個人が追加した写真はS3へ保存します。
- 一覧のページネーション、写真の並べ替え、ゴミ箱、元画像の保存には未対応です。

## API

| 操作 | エンドポイント |
| --- | --- |
| リンク情報取得 | `POST /groups/{groupId}/link-preview` |
| 写真アップロードの発行 | `POST /groups/{groupId}/items/{itemId}/photos/upload` |
| 写真の確定 | `POST /groups/{groupId}/items/{itemId}/photos` |
| 写真の削除 | `DELETE /groups/{groupId}/items/{itemId}/photos/{photoId}` |

すべてグループのBearerトークンが必要です。項目更新APIに`status`、`completedAt`、`expectedUpdatedAt`を追加しています。

## 確認方法

`backend`で`npm test`と`npx tsc --noEmit`、`frontend`で`npm run build`と`npm run lint`を実行します。Frontendのビルド後、`infra`で`ALARM_EMAIL=example@example.com npx cdk synth`を実行します。

ローカルではURL自動取得→保存、思い出への移動、複数写真の追加、一覧への反映、拡大表示、グループへの再訪を確認します。公開前にはデプロイ先でS3の署名付きPOST・CORS・署名付きGETも確認してください。ローカルAPIはS3自体には接続しません。
